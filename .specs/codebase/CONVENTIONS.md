# CONVENTIONS: site-caio-eliziario

- **Styling:** Tailwind CSS com classes utilitárias. Uso de variáveis de cor como `primary`, `secondary` e `primary-light`.
- **Form Validation:** Sempre utilizar Zod + React Hook Form.
- **Tracking:** Sempre injetar dados do `LeadContext` em submissões de formulário.
- **Naming:** Componentes em PascalCase, arquivos em PascalCase (em `src/components`).
