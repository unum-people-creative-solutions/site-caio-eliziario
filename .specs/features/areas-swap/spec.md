# Feature Spec: Swap de Cards (Consumidor e Imobiliário)

## Overview
Inverter a ordem dos cards "Direito do Consumidor" e "Direito Imobiliário".

## Requirements

| ID | Requirement | Description |
|---|---|---|
| REQ-01 | Reordenar Cards | Trocar posições de "Direito do Consumidor" e "Direito Imobiliário". |

## Acceptance Criteria
- [x] "Direito Imobiliário" aparece na terceira posição (índice 2).
- [x] "Direito do Consumidor" aparece na quarta posição (índice 3).
